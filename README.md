# Personal Details Generator

## About the Project
The Personal Details Generator is a beginner-friendly web application developed using HTML, CSS, and JavaScript. It allows users to enter their personal information and dynamically generate a simple profile.

## Features
- Enter name
- Enter age
- Enter profession
- Generate a personal profile
- Simple and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Tools Used
- Visual Studio Code
- GitHub
- GitHub Pages

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use Live Server.
4. Enter your details.
5. Click the Generate Details button.

## Learning Outcomes
- Understanding JavaScript variables and functions
- Working with DOM manipulation
- Handling user input
- Connecting HTML, CSS, and JavaScript
- Publishing a website using GitHub Pages
